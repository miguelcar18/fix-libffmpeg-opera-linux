# fix-libffmpeg-opera-linux
Script para descargar y reparar el archivo libffmpeg.so más recientes para habilitar la reproducción de video (H.264) y streams en vivo en el navegador Opera para Linux, respaldando una copia de seguridad del archivo original en la carpeta donde se ejecuta este script.

Fuente donde se obtienen el archivo libffmpeg.so: https://api.github.com/repos/nwjs-ffmpeg-prebuilt/nwjs-ffmpeg-prebuilt/releases/latest
Repositorio: https://github.com/nwjs-ffmpeg-prebuilt/nwjs-ffmpeg-prebuilt/
